# Dependency Graph Analyzer

## Общее описание

Dependency Graph Analyzer - это инструмент командной строки для анализа и визуализации графа зависимостей npm пакетов. Программа позволяет строить полные графы зависимостей, обнаруживать циклические зависимости, определять порядок загрузки и генерировать визуальные представления в формате SVG.

Особенности:

Полностью самостоятельная реализация без использования готовых менеджеров пакетов

Поддержка реального npm реестра и тестовых репозиториев

Множественные форматы вывода: SVG, ASCII-дерево, Mermaid

Обнаружение и обработка циклических зависимостей

Топологическая сортировка для определения порядка загрузки

## Функции и настройки

### Основные функции

| Функция | Описание |
|---------|-----------|
| build_dependency_graph() | Построение графа зависимостей алгоритмом DFS |
| generate_mermaid_graph() | Генерация Mermaid-диаграммы |
| print_dependency_tree() | Вывод ASCII-дерева зависимостей |
| calculate_load_order() | Топологическая сортировка графа |
| analyze_graph_statistics() | Анализ статистики графа |
| save_mermaid_svg() | Конвертация Mermaid в SVG |

### Параметры командной строки

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| --package-name | string | react | Имя анализируемого пакета |
| --repo-url | string | https://registry.npmjs.org | URL репозитория или путь к файлу |
| --test-repo | flag | False | Режим тестового репозитория |
| --version | string | latest | Версия пакета |
| --output | string | dependency_graph.svg | Выходной SVG файл |
| --show-tree | flag | False | Вывод ASCII-дерева |
| --filter | string |  | Фильтр пакетов по подстроке |
| --show-load-order | flag | False | Показать порядок загрузки |
| --demo-test-cases | flag | False | Демонстрация тестовых случаев |
| --generate-mermaid | flag | True | Генерация Mermaid диаграммы |
| --demo-visualization | flag | False | Демонстрация визуализации |
| --compare-with-npm | flag | False | Сравнение с npm инструментами |

## Сборка проекта и запуск

### Предварительные требования

Python 3.7 или выше

Node.js и npm (для генерации SVG)

Доступ к интернету (для работы с npm реестром)

### Установка зависимостей

```bash
# Установка mermaid-cli для генерации SVG
npm install -g @mermaid-js/mermaid-cli

# Проверка установки
mmdc --version
```

### Запуск приложения

```bash
# Базовая команда
python main2.py

# Справка по параметрам
python main2.py --help
```

### Тестирование

```bash
# Демонстрация тестовых случаев
python main2.py --demo-test-cases

# Демонстрация визуализации для трех пакетов
python main2.py --demo-visualization

# Сравнение с npm инструментами
python main2.py --compare-with-npm
```

## Примеры использования

### 1. Базовый анализ пакета

```bash
# Анализ React с генерацией SVG
python main2.py --package-name react --version 18.2.0 --output react_graph.svg --show-tree
```

Результат:

График зависимостей в react_graph.svg

ASCII-дерево в консоли

Статистика графа

### 2. Анализ с фильтрацией

```bash
# Исключение пакетов с 'dev' в названии
python main2.py --package-name express --filter "dev" --show-tree
```

### 3. Работа с тестовым репозиторием

```bash
# Создание тестового файла
echo '{
  "A": {"versions": {"1.0.0": {"dependencies": {"B": "^1.0.0"}}}},
  "B": {"versions": {"1.0.0": {"dependencies": {"C": "^1.0.0"}}}},
  "C": {"versions": {"1.0.0": {"dependencies": {}}}}
}' > test_repo.json

# Анализ тестового репозитория
python main2.py --package-name A --repo-url test_repo.json --test-repo --show-tree
```

### 4. Определение порядка загрузки

```bash
# Анализ порядка загрузки для lodash
python main2.py --package-name lodash --show-load-order --show-tree
```

### 5. Полный анализ с визуализацией

```bash
# Комплексный анализ пакета express
python main2.py \
  --package-name express \
  --version 4.18.0 \
  --output express_dependencies.svg \
  --show-tree \
  --show-load-order \
  --filter "test"
```

## Форматы вывода

### SVG диаграмма

Генерация: через Mermaid CLI

Особенности: интерактивность, масштабируемость

Стили: корневой пакет и циклические зависимости выделены цветом

### ASCII-дерево

```
ГРАФ ЗАВИСИМОСТЕЙ (ASCII-дерево)
============================================================
└── react@18.2.0
    ├── loose-envify@1.4.0
    │   └── js-tokens@4.0.0
    └── js-tokens@4.0.0 [ЦИКЛ]
```

### Mermaid код

```
graph TD
    react[react]:::root
    react --> loose_envify
    react -.-> js_tokens
    classDef root fill:#e1f5fe,stroke:#01579b,stroke-width:2px
    classDef cyclic fill:#ffebee,stroke:#c62828,stroke-width:2px
```

## Сравнение с npm инструментами

### Сходства

Анализ дерева зависимостей

Обнаружение циклических зависимостей

Поддержка различных типов зависимостей

### Различия

| Аспект | Наш инструмент | npm |
|--------|----------------|-----|
| Алгоритм обхода | DFS без рекурсии | С учетом версионных политик |
| Визуализация | SVG диаграммы + ASCII-дерево | Текстовое дерево |
| Обработка версий | Базовая | Сложное разрешение конфликтов |
| Peer dependencies | Включает в общий граф | Особая обработка |
| Фильтрация | По подстроке в имени | Ограниченная |

### Рекомендации по использованию

Для визуализации: используйте наш инструмент с --generate-mermaid

Для разрешения версий: используйте npm install

Для точного анализа: используйте npm ls --all

Для тестирования: используйте тестовый режим --test-repo

## Обработка ошибок

Программа включает комплексную обработку ошибок:

Валидация параметров: проверка корректности входных данных

HTTP ошибки: обработка 404, таймаутов, сетевых проблем

JSON парсинг: валидация структуры ответов

Файловые операции: проверка существования и доступности файлов

Циклические зависимости: обнаружение и маркировка циклов
